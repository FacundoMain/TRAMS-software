# TRAMS Software

Software desarrollado para la generación y validación de TRAMs (Treatment Response Assessment Maps) a partir de estudios de resonancia magnética.

## Funcionalidades

- Lectura de estudios DICOM.
- Registro rígido y deformable de imágenes.
- Generación de mapas TRAMs.
- Validación de la correspondencia espacial bajo TG-132.
- Exportación de resultados.

## Requisitos

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
python Looped_NERV.py
```
